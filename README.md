# Hospital Patient Care Analytics

End-to-end business intelligence project built on hospital patient care data.

## Objective
Turn raw patient care records into clear, interactive insights that support operational and management decisions.

## Tools
- **Python:** data extraction, cleaning, and ETL scripting
- **MySQL:** data storage and querying
- **Power BI & DAX:** data modeling, measures, and interactive dashboard

## Process
1. Extract and clean the raw data with Python
2. Load it into a MySQL database through ETL scripts
3. Build the data model and DAX measures in Power BI
4. Design an interactive dashboard for analysis
